# 使い方

## 画面の構成

| 領域 | 内容 |
| --- | --- |
| 上段バー | RUN / SINGLE、サンプリングレート、深度、エンジン、トリガモード、状態表示 |
| 左端の列 | ch 名と割り当て GPIO (`inv` 表示は論理反転中) |
| 波形エリア | 時間ルーラ、8 ch のトレース、デコード注釈 2 行 |
| 中段パネル | カーソル、ch ごとの測定値、状態とメッセージ |
| 下段バー | ズーム / パン / カーソル操作と各種オーバーレイの呼び出し |

## 上段バー

- **RUN / STOP** — 連続取り込みの開始と停止。
- **SINGLE** — 1 回だけ取り込んで停止。
- **レート `-` `+`** — 100 kSa/s 〜 40 MSa/s。実際に出るレートは状態表示の
  `@ x.xxx MHz` を見てください (PARLIO はハードウェア分周、CPU は実測値)。
- **深度 `-` `+`** — 64 kSa 〜 8 MSa。深度を変えると現在の取り込みは破棄されます
  (レート変更では破棄されません)。
- **ENG** — `AUTO` / `PARLIO` / `CPU`。AUTO は PARLIO が使えればそちらを選びます。
  PARLIO を明示的に選んで使えなかった場合は理由がメッセージに出ます。
- **AUTO / NORMAL / SINGLE** — トリガモード。

### レートと深度の決め方

観測したい最速のエッジに対して **5〜10 倍** のレートが目安です。
取り込み時間は `深度 ÷ レート` なので、例えば 1 MSa/s x 2 MSa = 2 秒。
中段パネルの `window` にこの値が出ます。

CPU エンジンで深く遅い取り込みをすると、その間 UI は止まります (取り込み中は
1 サンプルも落とさないためです)。

## トリガ

`Trigger` ボタンでオーバーレイを開きます。

- ch のボタンをタップするたびに
  `--` → `Rise` → `Fall` → `Both` → `High` → `Low` → `--` と巡回します。
- **エッジ条件どうしは OR**、**レベル条件どうしは AND**、両方あるときは
  「いずれかのエッジ AND すべてのレベル」。
  例: CH0=`Rise`, CH1=`Low` → 「CH1 が Low の間に CH0 が立ち上がったら」。
- **pre %** はプリトリガの割合です。25% なら画面の左 1/4 がトリガ前。
- **Clear all** で全 ch を `--` に戻します。条件がひとつも無ければ
  トリガ無し (取り込んだものをそのまま表示) になります。

モードの違い:

| モード | 条件が見つからないとき |
| --- | --- |
| AUTO | そのまま表示する |
| NORMAL | 5 秒間、取り込みと検索を繰り返す。その間は前の画面が残る |
| SINGLE | 1 回だけ取り込んで停止 |

## 波形操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ | 左右にパン |
| 2 本指ピンチ | 時間軸ズーム (指の中点が固定される) |
| タップ | アクティブなカーソルをその位置へ |
| `Zoom-` `Zoom+` | 画面中央を軸に 2 倍ずつズーム |
| `Fit` | 取り込み全体を画面に収める |
| `Auto` | 各 ch の最小パルス幅の中央値が約 3 px になるズームに合わせる (取り込み直後の既定) |
| `|<` `>|` | 先頭 / 末尾へ |
| `<<` `>>` | 半画面ずつスクロール |
| `Trig` | トリガ位置へジャンプ |
| `Cur A` `Cur B` | 置きたいカーソルを選ぶ (選択中が反転表示) |
| `Clr` | カーソルを消す |

カーソルを 2 本置くと、中段パネルに `dt` とその逆数 (周波数) が出ます。

ズームアウトしても 1 サンプルだけのパルスは縦線として残ります (間引きでは
なく OR/AND の要約で描いているためです)。

## チャンネル

`Channels` オーバーレイで、ch ごとに

- **SHOWN / hidden** — 表示のオンオフ。隠すと残りの ch のレーンが広がります。
- **INVERTED / normal** — 論理反転。オープンコレクタや反転プローブ用です。
  波形・測定・CSV・VCD すべてに反映されます。

## プロトコルデコード

`Decode` オーバーレイで種類を選び、ch を割り当てます。設定を変えるたびに
自動で再デコードされます (`Decode now` で明示的に走らせることもできます)。

### UART

| 項目 | 説明 |
| --- | --- |
| Line | 信号の ch |
| Baud | `auto` か固定値。`auto` は最小パルス幅を 1 ビットとみなして推定します |
| Data bits | 5〜9 |
| Parity | N / E / O |
| Stop bits | 1 / 2 |
| Polarity | `idle high` が通常の TTL シリアル。反転プローブなら `inverted` |
| Bit order | 通常は LSB first |

上の行にデータバイト (`55 'U'` のように印字可能文字も表示)、下の行に
`S` (スタート) / `P` (パリティ) / `T` (ストップ) が出ます。ストップビットが
崩れているフレームは赤で `T!` になります。

オートボーは「1 ビット幅のパルスが最低 1 つある」ことが前提です。
`0x00` や `0xFF` ばかりのストリームでは外すので、その場合は固定値にしてください。

### I2C

SCL と SDA の ch を割り当てるだけです。`START` / `Sr` / `STOP`、アドレス
(`50 W` のように R/W 付き)、データバイトが上の行、ACK (`A`) / NAK (`N`) が
下の行に出ます。

### SPI

CLK は必須、MOSI / MISO / CS は `--` で無効にできます。CS を `--` にすると
常時選択として扱います。CPOL / CPHA でサンプルエッジが決まります
(CPOL=CPHA のとき立ち上がりでサンプル)。MOSI が上の行、MISO が下の行です。

## microSD への保存

`Save` オーバーレイから。カードは初回アクセス時に自動でマウントされます。
ファイルは `/la/` 以下に連番で作られます。

| ボタン | 出力 | 内容 |
| --- | --- | --- |
| Save CSV (view) | `/la/capNNNN.csv` | **表示範囲のみ**、1 サンプル 1 行。時刻はトリガ基準の秒 |
| Save VCD (all) | `/la/capNNNN.vcd` | 取り込み全体。値の変化点のみ。PulseView / GTKWave で開けます |
| Save decode | `/la/decNNNN.txt` | デコード結果をタブ区切りで |
| Screenshot BMP | `/la/shotNNNN.bmp` | 画面全体の 24 bit BMP |

CSV を全体で出さないのは、8 MSa だと数十 MB になって書き込みに何分もかかる
ためです。全体が必要なら VCD を使ってください。

### PulseView で開く

1. VCD を PC にコピー
2. PulseView で `Import Value Change Dump data` を選ぶ
3. そのまま sigrok のデコーダ群が使えます

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 全 ch が High のまま | プローブが浮いている (内部プルアップが効いている)。GND を共通にしたか |
| 波形がガタつく | レートが足りない。信号の 5〜10 倍まで上げる |
| `UNTRIG` のまま | トリガ条件が厳しすぎる。`Clear all` で条件を外して素の波形を見る |
| PARLIO が選ばれない | `Info` オーバーレイで理由を確認。内部 RAM 不足なら深度を下げる |
| SD に保存できない | `Info` / `Save` のエラー表示を確認。FAT32 でフォーマットしたカードを使う |
| 期待より遅いレートしか出ない | ENG が `CPU` になっていないか。CPU エンジンの上限はループ速度で決まります |
